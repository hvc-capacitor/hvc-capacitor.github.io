# HVC Cross-Reference & Replacement Guides

**Live site: https://hvc-capacitor.github.io/**

Cross-reference and replacement data for discontinued and hard-to-source high voltage components, published by [HVC Capacitor Manufacturing Co., Ltd.](https://www.hv-caps.com/) (Shenzhen, China).

## Capacitors

- [Murata DHS / DHR cross-reference](https://hvc-capacitor.github.io/murata-dhs-dhr-cross-reference/) — discontinued screw-terminal and radial HV ceramic capacitors
- [Vishay 715C cross-reference](https://hvc-capacitor.github.io/vishay-715c-cross-reference/) — 10–50 kV N4700 screw-terminal series
- [TDK UHV / FHV alternative](https://hvc-capacitor.github.io/tdk-uhv-fhv-alternative/) — ultra-high-voltage screw-terminal capacitors
- [AVX HP / HD alternative](https://hvc-capacitor.github.io/avx-screw-terminal-capacitor-alternative/) — end-of-life screw-terminal capacitors
- [SAMWHA alternative](https://hvc-capacitor.github.io/samwha-hv-ceramic-capacitor-alternative/)
- [HEC / Vishay RF power alternative](https://hvc-capacitor.github.io/hec-vishay-rf-power-capacitor-alternative/) — HT50 / HT57 types
