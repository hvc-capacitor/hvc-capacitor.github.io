Vishay 715C High Voltage Capacitor Cross-Reference

Vishay's 715C series is a screw-terminal high voltage ceramic capacitor line (up to 50 kV, N4700 dielectric) used in X-ray generators, RF amplifiers and HV power supplies. Factory lead times for the 715C series typically run 25–42 weeks. HVC lists replacements for common 715C part numbers below.

HVC's screw-terminal series shares the same N4700 dielectric class and mounting geometry, and is available in the same 10–50 kV window — with additional sizes above 50 kV where the application allows a larger can.
